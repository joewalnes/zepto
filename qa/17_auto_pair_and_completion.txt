ID:       QA-CPLT-021
NAME:     Ctrl+Space is context-sensitive (completion vs. palette)
PRIORITY: P2
FEATURE:  completion palette
RELATED:  QA-REG-021

STEPS
  1. On an empty line (cursor at col 0), press Ctrl+Space.
  2. Escape, type a word so the cursor sits right after a word character,
     press Ctrl+Space again.

VERIFY
  - Step 1: the command palette opens (default command list visible).
  - Step 2: the completion menu opens instead — the palette's default
    command list must NOT appear. (Editor.pm ~1292-1312: Ctrl+Space
    triggers completion when the character immediately before the cursor
    is a word character, and opens the palette otherwise.)
  - Editor remains fully responsive to typing afterward either way.
  - Discovered while writing QA-REG-021 (Save As via Ctrl+Space right
    after typing content silently typed the command name into the
    document instead of running it) — that script now uses Ctrl+S
    instead to sidestep the ambiguity.
