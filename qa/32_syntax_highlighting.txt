================================================================================
32 — Syntax Highlighting
================================================================================

Covers: 52 language grammars, detection (extension / filename / shebang),
multi-line constructs, embedded languages, incremental re-highlighting,
Save As activation.

For a per-language feature matrix see lib/Zepto/Syntax/*.pm and
tests/samples/{lang}_complete.{ext} + {lang}_complete.expected.

--------------------------------------------------------------------------------

NAME:     Highlighting activates on file load

STEPS

  - Strings colored green.
  - Comments colored blue-gray.
