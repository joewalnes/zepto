================================================================================
24 — Recent Files (Ctrl+E)
================================================================================

Covers: ⌃E recent files picker, persistence to StateStore, MRU sort, temp-
file filter, size cap.

--------------------------------------------------------------------------------

ID:       QA-RCN-001
NAME:     ⌃E opens recent files list
PRIORITY: P0
FEATURE:  recent

STEPS
  1. Open and close several files.
  2. Press ⌃E.

VERIFY
  - Palette opens in "recent_files" mode.
  - Title shows "Recent Files" with ⌃E glyph.
  - List includes recently-opened files, MRU first.
  - Each item shows icon, filename, directory.

ID:       QA-RCN-004
NAME:     Recent persists across restart (REGRESSION)
PRIORITY: P1
FEATURE:  recent persistence

SETUP
  Delete ~/.config/zepto/recent_files (or StateStore recent_files).

STEPS
  1. Open file X.
  2. Quit zepto.
  3. Relaunch.
  4. ⌃E.

VERIFY
  - X appears in the recent list.

ID:       QA-RCN-005
NAME:     Temp files filtered out (REGRESSION)
PRIORITY: P2
FEATURE:  recent temp-filter
RELATED:  bugs.md P2 "history.json recent_files cluttered with temp files"

SETUP
  Open a file from /tmp (e.g. ./zepto /tmp/throwaway.txt).

STEPS
  1. Quit.
  2. Relaunch, press ⌃E.

VERIFY
  - /tmp/throwaway.txt is NOT in the recent list.
  - Same for /private/tmp/* and /var/folders/*.
