================================================================================
01 — Installation and CLI
================================================================================

Covers: the zepto binary itself, CLI flags, env vars, install flow, self-
installer, version reporting, help output.

Reference: /Users/joe/src/zepto/zepto (top-level argv parsing),
           /Users/joe/src/zepto/install.sh, /Users/joe/src/zepto/Formula/.

--------------------------------------------------------------------------------

ID:       QA-CLI-001
NAME:     Binary runs with no args and no files
PRIORITY: P0
FEATURE:  launch

SETUP
  ./zepto built via `make build`.

STEPS
  1. Run `./zepto` with no arguments (in a directory that is not a git repo).
  2. Observe initial state.

VERIFY
  - Editor opens to an untitled, empty tab.
  - File tree is visible on left (default when no file arg).
  - Status bar shows at least the cursor-pos pill (⏵ 1:1 ⌃G) and the
    Commands palette pill on the right (⌃␣ Commands).
  - No error output on stderr.
  - Cursor is positioned at row 1, col 1 of editor area.

ID:       QA-CLI-007
NAME:     --no-nerd-font disables glyphs
PRIORITY: P2
FEATURE:  cli-flag

STEPS

  2. Observe tab bar, status bar pills, file tree (if toggled on).

VERIFY
  - Rounded caps, folder glyphs, icon glyphs are replaced with ASCII
    equivalents (parentheses, `[F]` / `[D]`, single chars).
  - Layout remains readable and complete — no missing characters.
  - Nerd Font toggle pill in palette shows "off".

NOTES
  `--no-powerline` and `-P` are documented backwards-compat aliases for
  `--no-nerd-font`. Test both.

ID:       QA-CLI-013
NAME:     --install copies binary to default location
PRIORITY: P1
FEATURE:  installer

SETUP

  shell if possible.

STEPS
  1. Run `./zepto --install`.
  2. When done, run `~/.local/bin/zepto --version`.

VERIFY
  - Script reports destination path.
  - Copies successfully, sets exec permissions.
  - Installed binary runs and prints same version.
  - Exit code 0.

NOTES
  Clean up after: `rm ~/.local/bin/zepto` if desired.

  (no CPAN modules installed).

STEPS

  2. Type a few characters, save (⌃S), quit (⌃Q).

VERIFY
  - No "Can't locate X.pm" or other module errors.
  - Full editing loop works.

NOTES

  any regression here violates Rule 1 of CLAUDE.md.
