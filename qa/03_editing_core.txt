================================================================================
03 — Core Editing
================================================================================

Covers: character insertion, delete/backspace, Enter+auto-indent, Tab/
Shift+Tab, bracketed paste, dirty flag, cursor tracking.

--------------------------------------------------------------------------------

ID:       QA-EDIT-001
NAME:     Insert plain ASCII
PRIORITY: P0
FEATURE:  insert

SETUP
  Launch with empty file: `./zepto /tmp/zqa_edit.txt`.

STEPS
  1. Type `hello world`.

VERIFY
  - Text appears at cursor position.
  - Cursor advances after each character.
  - Tab label shows modified indicator (●).
  - Status bar cursor-pos pill updates (1:1 → 1:12).

ID:       QA-EDIT-015
NAME:     Native terminal paste does not cascade indent (REGRESSION)
PRIORITY: P1
FEATURE:  paste
RELATED:  bugs.md P1 "Native terminal paste (Cmd+V) causes cascading indentation"

SETUP

    def a():
        return 1
    def b():
        return 2

STEPS
  1. Use terminal's native paste (Cmd+V on macOS, Shift+Insert elsewhere).

VERIFY
  - Pasted text retains its original indentation.
  - Indent is NOT doubled/tripled on subsequent lines.
  - Bracketed-paste mode correctly suppresses auto-indent during the paste.
