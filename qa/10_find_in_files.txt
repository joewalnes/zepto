================================================================================
10 — Find in Files
================================================================================

Covers: Ctrl+Shift+F cross-file search, backends (git grep / rg / grep /
perl), scope cycling (Tab/Shift+Tab), grouped results, clicking result.

--------------------------------------------------------------------------------

ID:       QA-FIF-001
NAME:     Ctrl+Shift+F opens find-in-files palette
PRIORITY: P0
FEATURE:  fif

STEPS
  1. Launch zepto in a directory with source files.
  2. Press ⌃⇧F.

VERIFY
  - Palette opens in "find in files" mode.
  - Title shows "Find in Files" or similar.
  - Input field focused with empty query.
  - Scope indicator shown (e.g. "project").

--------------------------------------------------------------------------------

ID:       QA-FIF-002
NAME:     Query finds matches across files
PRIORITY: P0
FEATURE:  fif

STEPS

VERIFY

    context.
  - Relative paths shown.

ID:       QA-FIF-013
NAME:     ReDoS protection in FIF
PRIORITY: P2
FEATURE:  fif security
RELATED:  bugs.md P2 "ReDoS protection is length-only, no timeout"

STEPS
  1. ⌃⇧F, regex ON.
  2. Paste a pattern > 1000 chars.
  3. Or: try catastrophic backtracking pattern like `(a+)+$`.

VERIFY
  - Pattern rejected if too long.
  - Alarm-based timeout kicks in, search aborts cleanly, editor stays
    responsive.
