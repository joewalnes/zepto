================================================================================
23 — File Picker (Ctrl+O)
================================================================================

Covers: ⌃O fuzzy file picker, tracked + untracked file discovery, natural
sort, path truncation, skip directories, tree auto-hide if launched
single-file.

--------------------------------------------------------------------------------

ID:       QA-PICK-001
NAME:     ⌃O opens file picker
PRIORITY: P0
FEATURE:  pick

STEPS
  1. Launch zepto in a directory with files.
  2. Press ⌃O.

VERIFY
  - Palette opens in "files" mode.
  - Title shows "Open File" or similar.
  - Input field focused.
  - List of files from project visible.
