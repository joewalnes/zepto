================================================================================
07 — Navigation
================================================================================

Covers: arrow keys, word motion (Alt+Arrow), home/end (smart cycling),
page up/down, ctrl+home/end, cursor affinity in wrap mode.

--------------------------------------------------------------------------------

ID:       QA-NAV-001
NAME:     Arrow keys move cursor one cell
PRIORITY: P0
FEATURE:  arrow

STEPS
  1. Open multi-line file.
  2. Press Up, Down, Left, Right.

VERIFY
  - Cursor moves one line up/down or one char left/right.
  - Position pill in status bar updates on each movement.
  - No additional side effects.

--------------------------------------------------------------------------------

ID:       QA-NAV-002
NAME:     Alt+Right moves by word (forward)
PRIORITY: P1
FEATURE:  word-motion

SETUP
  Line `hello  world_foo  123bar`, cursor at col 1.

STEPS
  1. Press Alt+Right.
  2. Observe cursor position.
  3. Repeat.

VERIFY
  - Cursor jumps to start of next word each press.
  - Punctuation is treated as word boundary.
  - Whitespace is skipped.

ID:       QA-NAV-004
NAME:     Home cycles: first-nonws → col 0 → doc start (REGRESSION)
PRIORITY: P1
FEATURE:  home smart
RELATED:  bugs.md P2 "More home/end"

SETUP
  Line with 4 leading spaces: `    indented`.
  Cursor at col 8 (mid-line).

STEPS
  1. Press Home.
  2. Press Home again.
  3. Press Home again.
  4. Press Home again.

VERIFY
  - Press 1: cursor moves to col 5 (first non-ws).
  - Press 2: cursor moves to col 1 (start of line).
  - Press 3: cursor moves to line 1, col 1 (doc start).
  - Press 4: stays at doc start (or cycles back).

ID:       QA-NAV-013
NAME:     Cursor at virtual EOL on short line (up/down nav)
PRIORITY: P2
FEATURE:  cursor

SETUP
  Line 1: "long line of text here" (22 chars).
  Line 2: "short" (5 chars).

STEPS
  1. Move cursor to col 15 on line 1.
  2. Press Down.
  3. Press Down again to line 3 (if exists) — or test returning.
  4. Press Up.

VERIFY
  - On line 2: cursor is at col 6 (end of "short") but "virtual" col
    position is remembered.
  - On return to line 1 (or equivalent longer line): cursor goes back
    to col 15.

NOTES
  This tests "cursor affinity" — a common editor behavior.
