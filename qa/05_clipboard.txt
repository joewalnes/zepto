================================================================================
05 — Clipboard
================================================================================

Covers: cut, copy, paste, UTF-8 preservation, no-selection = line, column
clipboard, OSC 52, system integration (pbcopy/xclip/wl-paste).

--------------------------------------------------------------------------------

ID:       QA-CLIP-001
NAME:     Copy then paste within editor (ASCII)
PRIORITY: P0
FEATURE:  copy paste

STEPS
  1. Type "hello".
  2. Select "ell" with Shift+Arrow.
  3. Press ⌃C.
  4. Move cursor to end of line.
  5. Press ⌃V.

VERIFY
  - Line becomes "helloell".
  - No garbled characters.

  2. Select a 3×4 block with arrow keys.
  3. Press ⌃C.
  4. Exit column mode (Esc).
  5. Move cursor to another line.
  6. Paste with ⌃V.

VERIFY
  - A rectangular block is inserted at the cursor.
  - Each line of the clipboard contents appears on its own line.
  - Behavior matches typical column-paste semantics.

ID:       QA-CLIP-013
NAME:     Cut/copy/paste in find bar
PRIORITY: P2
FEATURE:  input clipboard
RELATED:  QA-FIND-*

STEPS
  1. Press ⌃F.
  2. Type a query.
  3. Select all (⌃A) in find field.
  4. Press ⌃X.

VERIFY
  - Field is cleared.
  - Query is in clipboard.
  - Paste (⌃V) into field restores it.

NOTES
  In find-bar context, ⌃C is repurposed for case toggle.
