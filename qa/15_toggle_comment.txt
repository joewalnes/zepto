================================================================================
15 — Toggle Comment
================================================================================

Covers: ⌃/ (toggle comment) behavior per language, HTML context-aware
commenting (HTML vs CSS vs JS), comment alignment at minimum indent,
single-line and selection-span cases.

--------------------------------------------------------------------------------

ID:       QA-CMT-001
NAME:     Toggle comment adds line comment for current line
PRIORITY: P0
FEATURE:  comment

SETUP
  Python file (.py). Cursor on line `x = 1`.

STEPS
  1. Press ⌃/.

VERIFY
  - Line becomes `# x = 1`.
  - Prefix inserted at first non-whitespace position (respecting indent).

ID:       QA-CMT-012
NAME:     Known-correct languages (sanity per language)
PRIORITY: P2
FEATURE:  comment lang matrix

STEPS
  For each language file type, verify ⌃/ uses the correct prefix:
    .pl / .pm   → #
    .py         → #
    .rb         → #
    .sh / .bash → #
    .yaml       → #
    .toml       → #
    .ini        → ;   (or #, per syntax rules)
    .sql        → --
    .lua        → --
    .c / .cpp / .h → // (line) or /* */
    .java       → //
    .js / .ts   → //
    .go         → //
    .rs         → //
    .swift      → //
    .php        → //
    .cs         → //
    .css / .scss → /* */ (block) — may use line if supported
    .html / .xml → <!-- -->
    .md         → <!-- -->  (or no prefix if ambiguous)
    .tex        → %

VERIFY
  - Each type produces its expected comment prefix/suffix.
  - Reference: lib/Zepto/Syntax/*.pm `line_comment_prefix`/`comment_style`.
