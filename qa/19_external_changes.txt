ID:       QA-EXT-001
NAME:     Clean buffer silently reloads on external change (REGRESSION)
PRIORITY: P0
FEATURE:  reload
RELATED:  bugs.md P0 "Editor does not detect or reload externally changed files"

SETUP
  Open /tmp/zqa_ext.txt with content "foo".
  Do NOT modify in zepto.

STEPS
  1. In another terminal: `echo "bar" > /tmp/zqa_ext.txt`.
  2. In zepto, press any key (or interact somehow).

VERIFY
  - Buffer silently updates to show "bar".
  - No prompt.
  - Cursor position preserved (clamped if file shrank).

--------------------------------------------------------------------------------

ID:       QA-EXT-002
NAME:     Dirty buffer shows prompt on external change
PRIORITY: P0
FEATURE:  reload prompt

SETUP
  Open /tmp/zqa_ext.txt. Modify (don't save) — dirty flag set.

STEPS
  1. In another terminal: `echo "external edit" > /tmp/zqa_ext.txt`.
  2. Interact in zepto.

VERIFY
  - Prompt appears: "File changed on disk. [R]eload [K]eep local".
  - Pressing R reloads (loses local edits).
  - Pressing K dismisses prompt (local buffer preserved).

ID:       QA-EXT-003
NAME:     Reload clears undo/redo stacks
PRIORITY: P2
FEATURE:  reload undo

STEPS
  1. Edit file (builds undo stack).
  2. External edit + reload via R.
  3. Press ⌃Z.

VERIFY
  - Undo stack is empty ("Nothing to undo" or no change).
