================================================================================
13 — Word Wrap
================================================================================

Covers: ⌥Z toggle, continuation row rendering (↪), per-filetype defaults
(prose types), interaction with diff view, column selection, gutter VCS.

--------------------------------------------------------------------------------

ID:       QA-WRAP-001
NAME:     ⌥Z toggles word wrap
PRIORITY: P0
FEATURE:  wrap

STEPS
  1. Open file with a long line (wider than viewport).
  2. Press ⌥Z.

VERIFY
  - Long line now wraps to multiple visual rows.
  - Continuation rows are indented (hanging indent) or have ↪ indicator.
  - Press ⌥Z again — wrap disabled, long line is horizontally scrollable.
  - Toggle pill in status bar reflects state.

ID:       QA-WRAP-015
NAME:     Home/End on continuation rows
PRIORITY: P2
FEATURE:  wrap navigation
RELATED:  QA-WRAP-006

STEPS
  1. Long line wrapped across 3+ visual rows. Cursor on middle row.
  2. Press Home — should go to start of visual row (or logical line start).
  3. Press End — should go to end of visual row (or logical line end).

VERIFY
  - Home/End behavior is consistent with arrow key behavior on
    continuation rows.
  - Smart Home cycling works: first-nonws → col 1 → doc start.
