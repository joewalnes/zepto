# QA Test Catalog

Master index of every QA test case ID, referenced from `CLAUDE.md` Rule 8
and `qa/README.md`. This file is generated/regenerated by cross-referencing:

- **Documented cases**: `ID:` lines in `qa/NN_*.txt` (the manual test plan).
- **Executable coverage**: the `# QA-TAG-NNN:` header comment on each script
  in `qa/scripts/tier1/*.sh` and `qa/scripts/tier2/*.sh`.

To regenerate the coverage numbers (not the tables below — see note at the
end of this file), run:

```
perl qa/coverage.pl
# or
make qa-coverage
```

## Coverage summary

```
TOTAL: 592/724 (81.8%)
```

592 of the 724 documented test cases have at least one executable script in
`qa/scripts/tier1/` or `qa/scripts/tier2/`. The remaining cases are
documented-only (manual-QA-only) — most commonly because they require
visual/subjective judgment (pixel-level rendering, color contrast, "looks
right" checks) that isn't yet automatable, or because they haven't been
scripted yet. See "Uncovered IDs" call-outs inline below (status column
reads `no script`), or run `perl qa/coverage.pl` for the live, grouped list.

## ID stability

IDs are **stable and never renumbered**. Once a test case is assigned
`QA-TAG-NNN`, that ID refers to that test case forever, even across edits
to its steps or verification criteria. To retire a test case (e.g. the
feature was removed, or the case was superseded), mark it `[RETIRED]` in
place in the `qa/NN_*.txt` file — do not delete it or reuse its number.

New test cases use the next unused number within their tag — never reuse a
retired number.

## Known anomalies

These are pre-existing duplicate-ID situations in `qa/scripts/`, called out
here per repo convention rather than silently renamed (renaming would
change script filenames referenced elsewhere and risks masking that two
scripts intentionally cover the same documented case from different
angles):

- **`QA-UNDO-010`** — two tier1 scripts share this ID:
  `undo_010_ghost_retrigger.sh` and `undo_010_redo_stack.sh`.
- **`QA-UNDO-011`** — two tier1 scripts share this ID:
  `undo_011_after_reload.sh` and `undo_011_reload_clears.sh`.
- **`QA-SBAR-005`** — two tier2 scripts share this ID:
  `sbar_005_toggle_pills.sh` and `sbar_005_wrap_active.sh`.

`perl qa/coverage.pl` reports these under "IDs with more than one script"
on every run so they don't silently disappear.

## Status legend

- `[tier1]` — covered by a fast, headless-friendly tier1 script.
- `[tier2]` — covered by a tier2 script (slower / more setup, e.g. visual).
- `no script` — documented in the manual test plan only; no automation yet.
