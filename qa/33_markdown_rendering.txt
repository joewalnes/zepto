================================================================================
33 — Markdown Special Rendering
================================================================================

Covers: pretty-rendered Markdown tables (box-drawing borders, alignment,
striped rows, cursor-inside switches to raw), dimmed emphasis delimiters,
inline images (future).

--------------------------------------------------------------------------------

ID:       QA-MD-001
NAME:     Markdown table pretty-rendered (REGRESSION)
PRIORITY: P2
FEATURE:  md table
RELATED:  bugs.md P2 "Markdown table pretty-rendering"

SETUP
  Markdown file with:
    | Name | Age | Role |
    | ---- | --- | ---- |
    | Alice | 30 | Eng |
    | Bob | 25 | PM |
  Cursor OUTSIDE the table (say, above it).

STEPS
  1. Observe.

VERIFY
  - Box-drawing borders: `┌───┬───┐`, `│ a │ b │`, `├───┼───┤`, etc.
  - Column widths auto-aligned.
  - Header row bold + distinct bg.
  - Data rows alternating stripe bg.
