================================================================================
16 — Transform via Shell
================================================================================

Covers: ⌥T transform, pipes selection or current line through sh -c,
replaces inline, error handling, hint text.

--------------------------------------------------------------------------------

ID:       QA-XFM-001
NAME:     ⌥T opens transform input
PRIORITY: P1
FEATURE:  transform

STEPS
  1. Open file. Press ⌥T.

VERIFY
  - Footer input appears with prompt and hint text.
  - Hint shows example commands: `sort | uniq`, `tac`,
    `python3 -m json.tool`.
  - Input field focused.
