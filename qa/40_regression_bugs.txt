================================================================================
40 — Regression Tests (Every Fixed Bug)
================================================================================

One regression test per bug marked FIXED in bugs.md. Many of these duplicate
coverage from the feature files; that's intentional — this file is a
single flat index for "run every regression" workflows.

Each entry cross-references the primary test case (QA-xxx-###) and summarizes
what to check. Keep this file in sync with bugs.md: when a new bug is
FIXED, add a corresponding REG entry here.

Legend:
  CROSS-REF — the main feature-file test case that covers this bug.
  VERIFY    — the specific symptom that MUST NOT reappear.
