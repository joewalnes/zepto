================================================================================
14 — Line Operations
================================================================================

Covers: Move Line Up/Down (⌥↑/⌥↓), Duplicate Up (⌃U), Duplicate Down (⌥U).

--------------------------------------------------------------------------------

ID:       QA-LINE-001
NAME:     ⌥↑ moves current line up
PRIORITY: P1
FEATURE:  move-line

SETUP
  3 lines:
    apple
    banana
    cherry
  Cursor on "banana".

STEPS
  1. Press ⌥↑.

VERIFY
  - Lines reorder to:
      banana
      apple
      cherry
  - Cursor remains on "banana" (now line 1).

--------------------------------------------------------------------------------

ID:       QA-LINE-002
NAME:     ⌥↓ moves current line down
PRIORITY: P1
FEATURE:  move-line

SETUP
  Same as above. Cursor on "apple".

STEPS
  1. Press ⌥↓.

VERIFY
  - Lines reorder:
      banana
      apple
      cherry
  - Cursor follows "apple" to line 2.

ID:       QA-LINE-007
NAME:     Duplicate Down via palette
PRIORITY: P2
FEATURE:  duplicate palette

STEPS
  1. Open palette.
  2. Search "Duplicate Down".
  3. Execute.

VERIFY
  - A second identical line is inserted below the current line.
  - Cursor on the lower (new) line.

NOTES
  ⌃D is bound to Select Next Occurrence (multi-cursor), NOT Duplicate
  Down — Duplicate Down has its own direct shortcut, ⌥U (see
  QA-LINE-010). Historical users may expect ⌃D for duplicate; it isn't
  bound to it. See bugs.md P2 "Shortcut key for Duplicate Down" (FIXED).

ID:       QA-LINE-010
NAME:     ⌥U duplicates current line down (direct shortcut)
PRIORITY: P2
FEATURE:  duplicate shortcut
RELATED:  bugs.md P2 "Shortcut key for Duplicate Down"

SETUP
  Line `hello`.

STEPS
  1. Press ⌥U.

VERIFY
  - A second `hello` line is inserted below the original.
  - Cursor moves to the lower (new) `hello` line.
  - Palette entry "Duplicate Down" shows shortcut "⌥U".

NOTES
  ⌥U was chosen over ⌃⇧D: classic terminals deliver Ctrl+letter via a
  single control byte (0x01-0x1a) with no way to distinguish Shift —
  Ctrl+D and Ctrl+Shift+D are indistinguishable on the wire in most
  terminals (see InputParser.pm _parse_control). Alt+letter (ESC+char)
  reliably survives, so ⌥U was picked to pair mnemonically with the
  existing ⌃U (Duplicate Up) — same letter, "up" modifier vs "down"
  modifier — without colliding with any other bound Alt+letter.
