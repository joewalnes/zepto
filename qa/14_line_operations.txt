================================================================================
14 — Line Operations
================================================================================

Covers: Move Line Up/Down (⌥↑/⌥↓), Duplicate Up (⌃U), Duplicate Down
(palette-only after multi-cursor reassignment).

--------------------------------------------------------------------------------

ID:       QA-LINE-001
NAME:     ⌥↑ moves current line up
PRIORITY: P1
FEATURE:  move-line

SETUP
  3 lines:
    apple
    banana
    cherry
  Cursor on "banana".

STEPS
  1. Press ⌥↑.

VERIFY
  - Lines reorder to:
      banana
      apple
      cherry
  - Cursor remains on "banana" (now line 1).

--------------------------------------------------------------------------------

ID:       QA-LINE-002
NAME:     ⌥↓ moves current line down
PRIORITY: P1
FEATURE:  move-line

SETUP
  Same as above. Cursor on "apple".

STEPS
  1. Press ⌥↓.

VERIFY
  - Lines reorder:
      banana
      apple
      cherry
  - Cursor follows "apple" to line 2.

ID:       QA-LINE-006
NAME:     ⌃U duplicates current line above
PRIORITY: P1
FEATURE:  duplicate

SETUP
  Line `hello`.

STEPS
  1. Press ⌃U.

VERIFY
  - A second `hello` line is inserted above the original.
  - Cursor on the upper (new) `hello`.

--------------------------------------------------------------------------------

ID:       QA-LINE-007
NAME:     Duplicate Down via palette
PRIORITY: P2
FEATURE:  duplicate palette

STEPS
  1. Open palette.
  2. Search "Duplicate Down".
  3. Execute.

VERIFY
  - A second identical line is inserted below the current line.
  - Cursor on the lower (new) line.

NOTES
  ⌃D is bound to Select Next Occurrence (multi-cursor), NOT Duplicate
  Down. Historical users may expect ⌃D for duplicate; palette is the
  only shortcut path. See bugs.md P2 "Shortcut key for Duplicate Down".

--------------------------------------------------------------------------------

ID:       QA-LINE-008
NAME:     Duplicate across selection duplicates all selected lines
PRIORITY: P3
FEATURE:  duplicate

SETUP
  3 lines selected.

STEPS

VERIFY
  - 3 duplicated lines inserted above the block (or below, per spec).
  - Selection reflects the duplicated block.

ID:       QA-LINE-009
NAME:     Move + undo
PRIORITY: P2
FEATURE:  move-line undo

STEPS
  1. Perform ⌥↓ on a line.
  2. Press ⌃Z.

VERIFY
  - Line order reverts.
  - Cursor returns to original position.
