# About Zepto

Zepto is a modern, intuitive terminal text editor.

It's a single file with zero dependencies - just Perl 5.10+ and a terminal.
No plugins, no config files, no package managers. Download it and go.

## Philosophy

- **Discoverable** - every feature is findable through the command palette
- **Familiar** - keyboard shortcuts work the way you'd expect
- **Minimal** - one file, standard library only, no setup
- **Fast** - starts instantly, handles large files
