== Introduction

This document demonstrates *AsciiDoc* syntax for highlighting.
AsciiDoc is a lightweight markup language for writing documentation.

=== Basic Formatting

Text can be *bold*, _italic_, `monospaced`, or [.underline]#underlined#.
You can also use **bold within** a word and __italic within__ a word.

Superscript: E=mc^2^ and subscript: H~2~O.

== Code Blocks

Inline code: `System.out.println("Hello")`

.A Java example
[source,java]
----
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
----

.Shell commands
[source,bash]
----
#!/bin/bash
echo "Installing..."
sudo apt-get update
sudo apt-get install -y mypackage
----

....
This is a literal block.
No formatting is applied.
Special chars: * _ ` #
....
